Политика конфиденциальности

Приложение «Premier Card Club Косынка» (в игре — «Косынка 3D»; Android, пакет ru.codeofmind.klondike). Разработчик: Premier Card Club. Редакция от 21 ноября 2026 года.

Здесь описано, какие данные использует игра и сторонние сервисы, встроенные в неё, зачем они нужны и как их удалить. Игра не требует регистрации и не просит имя, телефон, адрес электронной почты или другие контактные данные.

1. Что хранится только на устройстве

  • Настройки: язык, оформление стола и карт, музыка, громкость, вибрация, камера, качество графики, режим раздачи, режим для слабовидящих, отметка о пройденном обучении.
  • Статистика до 300 последних партий: дата, режим, результат, ходы, подсказки, отмены, длительность. По ней считаются процент побед и рекорды.
  • Отметка о покупке версии без рекламы.

Эти данные не передаются разработчику и третьим лицам.

2. Реклама (Яндекс Реклама)

В бесплатной версии показываются баннер внизу экрана и, по желанию игрока, реклама с вознаграждением (подсказки). Рекламу показывает SDK Яндекс Рекламы (ООО «ЯНДЕКС»). Для подбора и показа рекламы, защиты от мошенничества и подсчёта показов SDK получает технические данные: модель и производитель устройства, версия Android, язык и регион системы, размер экрана, тип подключения к сети, IP-адрес, сведения о приложении, факты показа рекламы и нажатий на неё.

Игра предназначена для всех возрастов (0+), поэтому реклама запрашивается без персонализации: SDK получает признак ограниченной по возрасту аудитории, поведенческая (персонализированная) реклама не показывается, рекламный идентификатор Android приложение не запрашивает. Обработку данных SDK выполняет Яндекс по своей политике конфиденциальности. В версии без рекламы (BLACK) реклама не загружается.

3. Покупка версии без рекламы (RuStore)

Покупка выполняется через платёжный сервис RuStore (SDK RuStore Pay). Данные банковской карты и платёжные данные вводятся в платёжной форме RuStore и обрабатываются RuStore и банком; разработчик их не получает. Приложение получает от RuStore только сведения о покупке (идентификатор товара, статус оплаты), чтобы включить версию без рекламы и восстановить её после переустановки. Обработка выполняется по правилам и политике конфиденциальности RuStore (ООО «ВК»).

4. Обратная связь

Кнопка «Написать разработчику» открывает ваше почтовое приложение с черновиком письма на codeofmind.support@gmail.com. В черновик подставляются название и версия игры, модель устройства, версия Android, уровень графики, размер экрана и язык — чтобы разобраться в проблеме. Письмо уходит, только если вы нажмёте «Отправить»; служебную часть можно удалить. Письма хранятся в почтовом ящике поддержки, пока нужны для ответа, и удаляются по вашей просьбе.

5. Дети

Игра не собирает сознательно персональные данные детей. Реклама для всех пользователей запрашивается без персонализации.

6. Как удалить данные

Очистите данные приложения в настройках Android или удалите приложение — настройки, статистика и отметка о покупке будут удалены (покупка восстановится из RuStore при повторной установке). Чтобы удалить переписку с поддержкой, напишите на адрес выше. Учётных записей в игре нет.

7. Контакты

По вопросам обработки данных: codeofmind.support@gmail.com. Об изменениях этой политики сообщается новой редакцией на этой странице с новой датой.
